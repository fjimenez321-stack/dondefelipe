    Cómo entrar

    1. Abre Minecraft Java Edition 1.21.11 con Fabric.
    2. Multijugador, añadir server, pega la dirección de arriba.
    3. Si el server está cerrado, espera: se enciende por tandas de prueba.

    Qué es esto

    Un server de prueba temporal, montado en un PC para experimentar antes de dejarlo abierto al curso. El mundo se puede borrar y volver a empezar. Los datos de esta página se actualizan solos cada minuto.
